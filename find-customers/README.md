# Find Customers

B2B 获客专家：把一句模糊的「帮我找客户」推到「可联系的客户清单 + 已落库的线索 + 已发出的合规触达」——需求锁定、产业链下游分析、多源客户采集、线索暂存、邮件直推或发布获客、收尾定制询问。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **采集优先，不查库开场**：线上库只是临时存放处，历史不可靠；去重交给服务端按企业名称自动合并，采集前不查库。
- **需求锁定**：行业、产品定位、目标区域、客户画像，缺失项合并为**至多 1 轮追问**。
- **下游地图**：基于产业链推导「谁会买」，优先级按「需求强度 × 可触达性 × 决策周期」综合判断。
- **多源采集**：行业门户 / 协会、搜索引擎与官网、社区与垂直频道、模型知识兜底，逐条标 `来源·时间`。
- **线索暂存**：主通道写入 `mcp.fore.vip/crm`（需 open_key）；服务不可达时降级本地 CSV 并说明原因。
- **邮件直推**：带公开邮箱的客户经 Agent Mail 一对一推送，发出后回写状态「已触达」。
- **发布获客补偿**：可联系线索 < 5 条时切换「让客户找上门」，给渠道清单 + 合规范文 + 配图要点。
- **收尾询问**：交付后询问是否把流程固化成定制工作流。

## 使用示例

- 帮我找客户：我做包装印刷，想找江浙沪的下游买家
- 我的货该卖给谁？先帮我分析产业链下游行业和需求点
- 把这批客户线索存到线上，能给公开邮箱的客户发一封触达邮件

## 前提条件

- **线索落线上库需要 open_key**：到 https://fore.vip/web/key（Open Key 管理，需登录）生成。没有密钥时线索只能保存在本地 CSV，换机器查不到。
- **邮件直推需要 Agent Mail 连接器**：运行环境未连接时降级为邮件草稿，由用户自行发送，状态不回写。
